Bug Bounty Research Platform

A fully local, ethics-first research platform for structured bug bounty hunting with automated recon pipelines, finding lifecycle tracking, and a live MCP server so Claude Code can query recon data in context

V1 Complete — Hunting

Built for depth over breadth. The goal is finding logic flaws and chained vulnerabilities that automated tools miss. Four Temporal workflows handle program onboarding, automated recon, continuous monitoring, and finding lifecycle — all feeding into a 9-table PostgreSQL database. A private FastAPI dashboard shows program scores, new asset alerts, and a finding pipeline sorted by status. Phase 1 is active targeting IDOR and API security.
